# 影屿 · CineIsle

**一个打通 Emby 的本地播放器 —— 基于 mpvEx 二次开发**

包名 `app.cineisle.player` · 当前版本 `v1.0.3` · 构建变体 `standard` · 双播放内核（mpv / GSYVideoPlayer）

## 项目背景

想要一个自己用着顺手的 Emby 播放器，现成的都不太合适，于是找了个扎实的播放器做底座：**[mpvEx](https://github.com/marlboro-advance/mpvEx)**（底层是 mpv-android / libmpv）。mpvEx 是个好用的**本地**播放器，但不带 Emby 客户端 —— 所以有了 **影屿 / CineIsle**：在它之上补出一整套 Emby 客户端，再把想要的功能一个个加上去。

名字取自「电影的岛屿」。

## 功能

### Emby 客户端（本项目从零实现）

**服务器与账号**

- 多服务器管理：添加 / 编辑 / 删除 / 切换；地址支持 `http://主机:端口` 与 `https://域名`
- 用户名 + 密码登录（`POST /emby/Users/AuthenticateByName`），**登录成功才入库**
- 配置存 Room，当前服务器重启后自动恢复；Token 失效时自动重登
- 首页顶栏可下拉直接切换服务器

**首页**

- 媒体库入口卡片、继续观看（带进度条与「剩余 XX分XX秒」角标）、最新加入
- **全局搜索**：跨全部媒体库搜索（400ms 防抖），带**类型筛选**（全部 / 电影 / 剧集 / 单集 / 合集 / 演员，可多选）与**搜索历史**（存 Room，可单条删 / 一键清空）

**媒体库浏览**

- 分类：全部 / 继续播放 / 合集 / 收藏 / 文件夹
- 排序：名称 / 加入时间 / 播放时间 / 发行年份 / 首播日期 / 评分 / 影评评分 / 时长 / 播放次数 / 随机；切排序或升降序后列表回到第一条
- 卡片样式：海报 / 背景图 / 横幅
- 文件夹下钻：容器类条目用子媒体的缩略图拼 2×2 宫格封面
- **随机播放**：范围跟着当前屏幕上的结果走（搜索词与各项筛选条件全部生效），另有「只看收藏」随机
- 搜索：库内搜索，同样带类型筛选与历史（与首页共用一份）；搜索时隐藏上方分类行，切排序也不会再弹输入法
- 列表结果与滚动位置做进程内缓存，从详情页 / 播放器返回时不重新请求

**媒体库筛选**（工具行漏斗图标）

类型 / 标签 / 年份 / 官方分级、演员 / 导演、工作室、播放状态、清晰度、3D、字幕、评分门槛、只看收藏、中文字幕。点一下立刻生效，无需确认；条件按库各记一份。

**中文字幕筛选（客户端能力）**

Emby 没有这个维度，所以按条目的**路径**匹配。默认标记 `-C`，另支持 `-CHS` `-CHT` `CHI` `CHINESE` `GB` `BIG5` `中字` 等一批写法；标记表可在筛选项里增删，匹配范围可选整条路径或仅文件名。开启后扫全库，边扫边出结果。

**详情页**

- 剧照 + meta 摘要；播放区按进度显示「继续播放」，真看过的另给「从头播放 / 继续上次」
- 剧集按季 / 集展开；演职员点进演员作品页；类型 / 标签 chip 点进作品页
- 媒体信息（容器、编码、分辨率、码率、音轨、字幕轨、文件大小等）
- 更多菜单：编辑 / 刮削 / 刷新元数据、删除媒体
- 收藏、标记已看、一键加入离线下载队列

**播放与进度同步**

- 直链播放 `GET /emby/Videos/{Id}/stream?static=true`，不转码，交给本地内核解码
- 剧集连播：队列随 intent 传入，标题、随机、循环都正确
- 进度回传 `/Sessions/Playing[/Progress|/Stopped]`，多端进度互通
- 播放页内有 Emby 收藏按钮；切集自动刷新收藏 / 已看状态
- 外挂字幕按需拉取；图片按卡片宽度请求合适尺寸

**离线下载**

- 走 `GET /emby/Items/{Id}/Download` 拿原文件，支持 `Range` 断点续传
- Android 10+ 经 `MediaStore` 写公共 `Download/CineIsle`，**不需要存储权限**，半成品不外露
- 暂停时保留已下字节，继续时带 `Range` 追加重写，不重头下
- 最多同时下 2 个，其余排队；任务持久化，重启后可续传
- 不用系统 DownloadManager —— 它没有公开的暂停 / 继续 API

### 双播放内核

默认 **mpv**（功能最全），另备 **GSYVideoPlayer**（底层可挂 IJK / System / ExoPlayer）。有些片子换个内核就顺了。

- 切换方式：设置里选默认内核；播放页内一键互切（带队列、标题、进度）；筛选面板 / 详情页长按播放键用另一内核起播
- GSY 页照 mpv 的样式重画了一套控件，提供倍速 / 循环 / 锁屏 / 滤镜 / 显示比例 / 静音 / 截图 / 字幕 / 画中画 / 投屏 / 收藏等；mpv 独有的能力（滤镜链、着色器、章节等）在 GSY 页**直接不显示**而不是置灰
- GSY 有独立的一整页设置，与 mpv 严格隔离

### 其他

- **DLNA 投屏**（实验性）：自动发现局域网接收设备，详情页与播放页均有入口，可遥控播放 / 暂停 / 音量
- **播放体验**：视频预加载、连播下一集倒计时、记住每部剧的播放速度与音轨、切集不重置屏幕方向
- **界面**：竖屏控件精简、播放页按钮可自定义、设置可搜索、图片缓存管理、启动页
- **继承自 mpvEx**：本地文件播放、Material 3 Expressive、SMB / FTP / WebDAV、外部音轨与字幕、手势控制、画中画、后台播放、Anime4K 着色器

### 安全与隐私

- **密码加密落盘**：Emby 与 SMB / FTP / WebDAV 的密码统一用 Android Keystore 的 **AES-256-GCM** 加密，密文格式 `enc:v1:<iv>:<密文>`；密钥不可导出，光拿到 `mpvex.db` 解不开。老明文数据在 App 启动时就地重加密，无需迁移脚本。约定「DB 存密文、内存存明文」，加解密收口在仓库层
- **备份不带密码**：导出的 XML 会主动丢弃所有密码，导入后需重新填写
- **播放器不显示直链里的 `api_key`**：顶栏标题、通知栏、投屏名等纯展示位置统一脱敏；**交给播放内核的地址仍是原始的那一份，不影响播放**

### 中文本地化

补齐了大量此前仍是英文的文案：滤镜预设、播放配置名、进度条样式、播放器控件名、网络页、各类设置项与说明文本，以及排序与视图弹窗（标题 / 日期 / 大小 / 时长 / 视频数、升降序说法、显示项、列数等）。

> 排序选项有个坑：枚举名（`Title` / `Date` / `Size` …）**同时是持久化键**，不能直接改成中文，所以显示层另走一层 `label` 映射。

## 更新记录

### 1.0.3

- **搜索**：加类型筛选与搜索历史（存 Room，首页与媒体库共用）；搜索结果支持排序（客户端排序，服务端对 `SearchTerm + SortBy` 不保证生效）；修复搜索结果里切排序后一直转圈的问题
- **随机播放**：范围改为当前屏幕上的这批结果（搜索词与各项筛选条件全部生效），搜索时即打乱搜索结果
- **安全**：密码加密落盘；导出备份不含密码；播放器界面不再显示直链里的 `api_key`
- **媒体库**：切排序或升降序后列表回到第一条；进入搜索时隐藏上方分类行；工具行上的按钮（排序 / 筛选 / 样式 / 随机）在动作前会收掉输入法焦点，避免每切一次排序就弹一次键盘
- **本地化**：补齐排序与视图弹窗中文文案
- **外观**：封面角标底色由深蓝改为中性炭黑

## 构建

前置：JDK 17、Android SDK（build tools 34.0.0+）、Git。

```bash
./gradlew.bat --no-daemon -Pabi=arm64-v8a --console=plain :app:assembleStandardDebug
```

产物在 `app/build/outputs/apk/standard/debug/`。可选 ABI：`arm64-v8a`（推荐）、`armeabi-v7a`、`x86`、`x86_64`、`universal`。

> 依赖来自 Google Maven、Maven Central 与 JitPack。若本地 Gradle 挂了「只走单一镜像」的 init 脚本，会导致仅托管在 Maven Central 的依赖（如 `io.github.marlboro-advance:mpv-android`）解析失败。
>
> Emby 官方 Java SDK（`embyclient`）与 UPnPCast（DLNA 投屏）均以源码形式内置，不走 Maven。
