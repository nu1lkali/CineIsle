# 影屿 · CineIsle

**一个打通 Emby 的本地播放器 —— 基于 mpvEx 二次开发**

包名 `app.cineisle.player` · 当前版本 `v1.2.1` · 构建变体 `standard` · 双播放内核（mpv / GSYVideoPlayer）

## 项目背景

一开始用的是某款第三方 Emby 播放器。用着还行，但总有些自己想要的功能它没有，于是去提需求——作者不太愿意做，也没怎么回复。

那没辙了，自己做呗。

从零写一个播放器内核不现实，所以找了一个足够扎实的播放器做底座：**[mpvEx](https://github.com/marlboro-advance/mpvEx)**（底层是 mpv-android / libmpv）。mpvEx 本身是一个好用的**本地**播放器，但不带 Emby 客户端。

于是就有了 **影屿 / CineIsle**：在 mpvEx 上补出一整套 Emby 客户端，再把那些「自己用得上」的功能一个个加上去。

名字取自「电影的岛屿」——把自己想看的片子收在一个地方。

## 功能

### Emby 客户端（本项目从零实现）

**服务器与账号**

- 多服务器管理：添加 / 编辑 / 删除 / 切换；地址支持 `http://主机:端口` 与 `https://域名`
- 用户名 + 密码登录（`POST /emby/Users/AuthenticateByName`），**登录成功才入库**
- 配置存 Room，当前服务器重启后自动恢复；Token 失效时自动重登
- 首页顶栏可下拉直接切换服务器；下载与 Emby 维护常驻，低频功能收在「更多」里

**首页**

- 媒体库入口卡片、继续观看（带进度条与「剩余 XX分XX秒」角标）、最新加入
- **随便看看**：最新加入下面是一批可连播的推荐，随时「换一批」；可在设置里整块关掉
- **全局搜索**：跨全部媒体库搜索（400ms 防抖），带**类型筛选**（全部 / 电影 / 剧集 / 单集 / 合集 / 演员，可多选）与**搜索历史**（存 Room，可单条删 / 一键清空），输入时在下方给出**联想建议**（命中的字加粗）

**媒体库浏览**

- 分类：全部 / 继续播放 / 合集 / 收藏 / 文件夹 / **演员**（演员卡片左下角带作品数角标，点进去是 TA 的作品列表）
- 排序：名称 / 加入时间 / 播放时间 / 发行年份 / 首播日期 / 评分 / 影评评分 / 时长 / 播放次数 / 随机；切排序或升降序后列表回到第一条
- 卡片样式：海报 / 背景图 / 横幅；海报的下方标题可设**一行或两行**（默认一行，长片名选两行可看全）
- 文件夹下钻：容器类条目用子媒体的缩略图拼 2×2 宫格封面
- **随机播放**：范围跟着当前屏幕上的结果走（搜索词与各项筛选条件全部生效），另有「只看收藏」随机
- 搜索：库内搜索，同样带类型筛选与历史（与首页共用一份）；搜索时隐藏上方分类行，切排序也不会再弹输入法；搜索结果的排序在后台线程完成、排好整批一次渲染，并回到列表顶部
- 列表结果与滚动位置做进程内缓存，从详情页 / 播放器返回时不重新请求

**片单与推荐**（首页顶栏「更多」）

- **播放列表**：读取服务器上的播放列表，支持新建、增删条目、拖动排序、整份删除；列表内容可改名、可分享给别的客户端
- **猜你喜欢 / 连播**：以某部片为起点续播一批同类内容，攒成一个可连播的列表；推荐算法可选「用 Emby 的」或「本地算」，本地模式不依赖服务端支持，并可排除已看过的
- **合集**：同一部作品的不同版本收在一起

**媒体库筛选**（工具行漏斗图标）

类型 / 标签 / 年份 / 官方分级 / 评分、播放状态、字幕、只看收藏、中文字幕。多选类目点右侧「＋」弹出勾选框，选完以圆角标签挂在类目下方、点标签上的「×」可单独去掉；面板里怎么改都只是草稿，点底部「确定」才应用到列表（点「取消」原样丢弃）。条件按库各记一份。

**演职员合并（工具）**

Emby 的演员条目是按**名字**建的，名字写法只要不一样就是两条独立的人 —— 中英文混用、括号注释、全角半角、艺名本名，都会让同一个人裂开：演员作品页少一半片、演职员表出现重复面孔、收藏对不上。

「设置 → Emby 媒体库 → 演职员合并」（长按演员卡片也能进，会直接把这位演员带进去）提供归并工具：按名字搜演员、扫描全库找疑似重复、一键自动合并、也可以手动把不同名字的条目并到某一条上。合并会**写入服务器元数据**、所有客户端立即生效，之后可在「合并历史」里按批次撤销；需要管理员账号（非管理员整页只读）。另有可选的「合并后自动清理孤立演员」，**默认关闭**。

「判重规则」可以自己选，决定一键合并会把哪些组算成同一个人：**严格**（默认，名字相同且外部 ID 不冲突）、**同名即合并**（忽略外部 ID 冲突 —— 库里同名不同人的情况很少时用它，能一次清掉大量重复）、**含相近名**（名字互为前缀也算，最激进）。扫描结果始终全量列出，手动合并任何时候都能用，每组合并前也都会把保留项摆出来让你确认。

两段**名字完全一样**的条目也能合并：服务端是按名字认人的，两条同名时改写的演职员表会被原样退回、看上去「提示成功但没变」；现在合并时会先给其中一条临时加个编号后缀避开这种认法，归并完成后再改回原名（撤销时同样还原）。每次写完都会回服务器核对，核对不上会如实说明、不会假装成功。演员作品页会列出这个人参与的全部作品，合并完返回时列表自动刷新。

**长按复制**

详情页的片名、原名与演职员表里的演员名，以及演员作品页的姓名，长按即可复制到剪贴板（带触觉反馈与「已复制」提示）。

**中文字幕筛选（客户端能力）**

Emby 没有这个维度，所以按条目的**路径**匹配。默认标记 `-C`，另支持 `-CHS` `-CHT` `CHI` `CHINESE` `GB` `BIG5` `中字` 等一批写法；标记表可在筛选项里增删，匹配范围可选整条路径或仅文件名。开启后扫全库，边扫边出结果。

**详情页**

- 剧照 + meta 摘要；播放区按进度显示「继续播放」，真看过的另给「从头播放 / 继续上次」
- **顶部封面**：Primary 封面按 2:3 完整显示，剧照以缩略图放大后虚化打底；整个头部可做折叠滚动，收起时标题淡入工具栏
- **推荐**：按演职员表里的演员 / 导演反查 TA 的其他影片，客户端随机取样 6 条，点开直接进下一个详情页
- 剧集按季 / 集展开；演职员点进演员作品页；类型 / 标签 chip 点进作品页
- 媒体信息（容器、编码、分辨率、码率、音轨、字幕轨、文件大小等）
- 更多菜单：编辑 / 刮削 / 刷新元数据、删除媒体
- 收藏、标记已看、一键加入离线下载队列

**播放与进度同步**

- 直链播放 `GET /emby/Videos/{Id}/stream?static=true`，不转码，交给本地内核解码
- 剧集连播：队列随 intent 传入，标题、随机、循环都正确
- 进度回传 `/Sessions/Playing[/Progress|/Stopped]`，多端进度互通
- 播放页内有 Emby 收藏按钮；切集自动刷新收藏 / 已看状态
- 外挂字幕按需拉取；图片按卡片宽度请求合适尺寸

**离线下载**

- 走 `GET /emby/Items/{Id}/Download` 拿原文件，支持 `Range` 断点续传
- Android 10+ 经 `MediaStore` 写公共 `Download/CineIsle`，**不需要存储权限**，半成品不外露
- 暂停时保留已下字节，继续时带 `Range` 追加重写，不重头下
- 最多同时下 2 个，其余排队；任务持久化，重启后可续传
- 不用系统 DownloadManager —— 它没有公开的暂停 / 继续 API

### 双播放内核

默认 **mpv**（功能最全），另备 **GSYVideoPlayer**（底层可挂 IJK / System / ExoPlayer）。有些片子换个内核就顺了。

- 切换方式：设置里选默认内核；播放页内一键互切（带队列、标题、进度）；筛选面板 / 详情页长按播放键用另一内核起播
- GSY 页照 mpv 的样式重画了一套控件，提供倍速 / 循环 / 锁屏 / 滤镜 / 显示比例 / 静音 / 截图 / 字幕 / 画中画 / 投屏 / 收藏等；mpv 独有的能力（滤镜链、着色器、章节等）在 GSY 页**直接不显示**而不是置灰
- GSY 有独立的一整页设置，与 mpv 严格隔离

### 视界流

竖屏上下滑动连播，一次随机抽一批视频连着刷。媒体库工具行上的图标进入，随机条数在设置里改（默认 100 条）。

- **滑动跟手**：相邻几条各自起一个播放实例并提前缓冲好，滑过去只是把播放打开，不重新起播
- **手势三条，各占一块地盘**：左边缘竖滑调亮度、右边缘竖滑调音量、横拖调进度；中间那块留给翻页，互不抢
  - 亮度只改本页窗口，退出即恢复，不动系统亮度设置
  - 横拖起步那一小段是精调区（几秒级），之后线性铺满整片
  - 屏幕最顶和最底让给系统的下拉通知栏 / 上滑回桌面，不参与手势
- **控件**：单击暂停 / 继续，双击收藏，右侧一列是收藏 / 截图 / 横竖屏 / 重载，底部可拖进度
  - 收藏按钮与详情页共用同一套动效：弹跳 → 红心径向渐变 + 外发光 → 光环与星光扩散淡出
- **显示比例**：按屏幕当前尺寸等比缩放，**完整显示全部画面、不裁任何一格**，多出来的地方留黑边
  - 横屏视频在竖屏下上下留黑，竖屏视频转到横屏后左右留黑 —— 任何组合都能看到完整构图
  - 竖屏内容不提供旋转：转过去画面不会变大，两侧却凭空多出黑边，点了会提示原因
- 截图存进相册（`Pictures/CineIsle`）；出错会给一句人话 + 重试，不是干等黑屏；刷到队尾自动向服务器续拉下一批

> 视界流不用 mpv / GSY：这两个都是单实例内核，滑动只能换源重起。它另用一套多实例内核，与播放页的内核选择互不影响。

### 其他

- **标记为不喜欢**：详情页、播放页、视界流三处都能随手标记，长按写一句原因；设置里可分入口开关，并有一个管理页列出全部标记（单项左滑可取消标记 / 删除，支持全选操作）
- **DLNA 投屏**（实验性）：自动发现局域网接收设备，详情页与播放页均有入口，可遥控播放 / 暂停 / 音量
- **播放体验**：视频预加载、连播下一集倒计时、记住每部剧的播放速度与音轨、记住每部片的外挂字幕与字幕开关（重开 App 依然在）、切集不重置屏幕方向
- **界面**：竖屏控件精简、播放页按钮可自定义、设置可搜索、图片缓存管理、启动页
- **继承自 mpvEx**：本地文件播放、Material 3 Expressive、SMB / FTP / WebDAV、外部音轨与字幕、手势控制、画中画、后台播放、Anime4K 着色器

### 安全与隐私

- **密码加密落盘**：Emby 与 SMB / FTP / WebDAV 的密码统一用 Android Keystore 的 **AES-256-GCM** 加密，密文格式 `enc:v1:<iv>:<密文>`；密钥不可导出，光拿到 `mpvex.db` 解不开。老明文数据在 App 启动时就地重加密，无需迁移脚本。约定「DB 存密文、内存存明文」，加解密收口在仓库层
- **备份不带密码**：导出的 XML 会主动丢弃所有密码，导入后需重新填写
- **播放器不显示直链里的 `api_key`**：顶栏标题、通知栏、投屏名等纯展示位置统一脱敏；**交给播放内核的地址仍是原始的那一份，不影响播放**

### 中文本地化

补齐了大量此前仍是英文的文案：滤镜预设、播放配置名、进度条样式、播放器控件名、网络页、各类设置项与说明文本，以及排序与视图弹窗（标题 / 日期 / 大小 / 时长 / 视频数、升降序说法、显示项、列数等）。

> 排序选项有个坑：枚举名（`Title` / `Date` / `Size` …）**同时是持久化键**，不能直接改成中文，所以显示层另走一层 `label` 映射。

## 更新记录

### 1.2.1

- 修掉两个问题：设置里「不喜欢视频管理」的说明文字之前没翻译，中文系统下会显示英文，现在已全部汉化；点进那个设置页会闪退，现在正常打开
- 修掉布局问题：「标记为不喜欢」设置页之前没标题栏，页面内容会压在系统状态栏底下，现在补上了标题栏和返回按钮
- 修掉播放器里找不到「不喜欢」入口的问题：mpv 播放页的控制栏是按布局配置渲染的，出厂配置里没排这颗按钮，于是设置里明明写着「已开启」、播放器里却怎么都找不到。现在出厂就排好了，老版本升上来也会自动补上（如果你手动删过它，不会被塞回来）
- 修掉 GSY 播放页点了「不喜欢」没反应的问题：按钮只在切换上下集时才认当前这片，刚进播放器那段时间点了是没动静的。现在起播时就认，点下去一定有反馈
- 修掉 GSY 播放页投屏卡死的问题：关掉投屏面板后，面板残留的窗口会挡住整个页面，点哪都没反应、返回键也退不掉。现在关掉就真的关掉了，顺带把为该面板暂停的播放恢复回去
- 修掉视界流一进就闪退的问题
- 修掉 mpv **竖屏**里找不到「不喜欢」按钮的问题：竖屏和横屏用的是两套各自独立的控件排布，出厂时只排了横屏那一套，所以竖屏一颗都没有。现在竖屏也排上了，老版本升上来会自动补齐（只补你没手动改过的那一套）
- 修掉 mpv 横屏点了「不喜欢」提示「当前视频没有可标记的来源」的问题：它原先只在切换上下集时才认当前这片，刚进播放器那段时间点了就报这句话。现在起播时就认，随时点都有反应
- 「不喜欢」的**图标换了**：原来那个拇指向下容易被读成「点踩 / 差评」，实际意思是「我不想再看到这部」，现在换成**心碎**，和收藏那颗心正好是一对。标记之后图标**从空心变实心、并且转成红色**，一眼就能看出标没标（原来空心/实心在半透明的圆底上差别太小，看不出来）
- 修掉 GSY 播放页**竖屏与全屏两处按钮状态可能对不上**的问题：两处是各自独立的控件，之前只把状态推给其中一处，另一处会停在旧样子 —— 表现为「全屏标了、退出全屏又变回没标」。现在两边都跟着同一份状态走，不会不一致
- 修掉「不喜欢视频管理」页**侧滑按钮太矮**的问题：「取消标记」和「删除」现在和那一条条目一样高，不再是一小块扁扁的按钮
- 修掉 GSY 播放页**关掉投屏后暂停不了也播不了**的问题：投屏时暂停、关掉面板时恢复，这两步之前走了两套不同的接口，把播放器的内部状态搞乱了，于是关掉面板后播放/暂停键全都失灵。现在两步走同一套，关掉面板能正常接着播
- 修掉「在播放器里标记的视频，到管理页里显示『无标题』、缩略图也没有」的问题：播放页手上只有条目的编号、拿不到片名，标记时就把片名存成了空。现在起播时会带上片名，实在拿不到也会回服务器补一次；**以前已经标过的那些同样会自动补上**，不用你重新标记一遍
- 修掉管理页**点某一条完全没反应**的问题：点击后要先查一次服务器，而这个查询被界面自己的状态刷新给取消了，所以点了什么都不会发生、也不报错。现在点了能正常打开播放
- 管理页**长按某一条可以改原因**了 —— 以前只能在标记那一刻写一次，之后想改只能删了重标
- 修掉管理页侧滑按钮和条目**对不齐**的问题：按钮和卡片贴的不是同一个高度，滑开时明显错开一截。现在两者等高
- 侧滑按钮**继续修正**：上一版还是差 6dp —— 卡片里那层内容默认是上下居中的，只占内容高度，没跟卡片一起撑满。现在真正对齐了
- 详情页点「播放」后加了**加载提示**：从详情页到播放器起来有一段真实的等待，以前这段时间没有任何反馈、点了像是没反应。现在播放键会变成转圈并显示「正在打开播放器…」，这期间也不会被重复点开
- 修掉「不喜欢视频管理」**空页面那段说明文字排版难看**的问题：原来是三行、第二行孤零零一个字，现在按屏宽自然换行
- 「不喜欢视频管理」里的第二个侧滑按钮改成**「删除影片」**——以前它只是把本地的标记记录清掉，现在会**真的把片子从 Emby 媒体库移除、并删掉服务器磁盘上的源文件**（不可恢复）。因为这是不可逆的破坏性操作，单条和批量都会弹确认框、并且**要手动输入「删除」两个字才会放行**，确认框里会逐个列出要删的片子；批量删除会显示进度，删完告诉你成功几个、失败几个
- 修掉「不喜欢视频管理」侧滑按钮**和条目对不齐**的老问题（这次是彻底修好了）：根因是行高只设了下限、没有上限，导致按钮和卡片各自只占自己的内容高度，差了小二十个像素；现在两者严格等高
- 修掉上一版引入的回归：「取消标记 / 删除影片」两个按钮**常驻显示在条目左边、把卡片挤窄、还滑不掉**。原因是上一条修对齐时改动了这一行的排布方式，把"垫在卡片下面、滑开才露出"错改成了"并排摆着"；现在恢复成滑开才露出
- 修掉「设置 → 播放器 → 常规」里 **GSY 播放器那一项多带了个图标**的问题：同页其他设置项都不带图标，只有它带，看着格格不入。现在去掉了，整页风格统一
- 媒体库的**「视图」里新增「标题行数」**：片名太长时一行会被省略号截断、只认得前半截，现在可以调成**两行**看全（默认一行，最多两行）。卡片会相应变高、一屏能看到的条目会略少，按需自己选；紧凑列表不受影响
- 媒体库的**「视图」面板重新排版**：以前选项一多就超出一屏、必须来回滚，现在一屏就能放完 —— 排布方式 / 卡片样式改成横向一排按钮，两个数字调节并排摆；「视图」里那个按年份分组的排布方式，**按钮文案从「年份时间轴」简写成「年份」**（原来五个字在一排按钮里放不下会折成两行，三个按钮高度不齐）
- **「筛选」面板重新设计**：多选类目（类型 / 标签 / 年份 / 官方分级 / 评分）改成「类目名 + 右侧＋号」，点＋弹出勾选框、选完点确定，已选项以**带叉号的圆角标签**挂在类目下方，点叉即可单独去掉；开关类（中文字幕 / 只看收藏）与下拉类（播放状态 / 字幕）保持原有形态。同时**去掉了演员 / 导演、工作室、清晰度、3D** 四个维度
- **筛选改为「确定才生效」**：以前在面板里每勾选一个类目就会立刻重新筛一遍列表，改一项等一次、手感很碎；现在面板里怎么调都只是暂存，**点底部「确定」统一应用**，点「取消」则原样丢弃
- **修复筛选「类型 / 标签」导致列表报「服务器出错（500）」**：以前这两项是按**名字**发给服务器筛的，部分服务器的媒体库数据表结构有残缺，一按名字查就自己出错、直接返回 500；现在改成按**类型 / 标签的编号**筛（与 Emby 官方网页端同一套做法，正常分页、结果准确），只有遇到确实不支持编号筛选的服务器时，才自动退回客户端本地筛选，不会再报错
- 首页长按媒体库弹出的**「调整顺序号」面板重新排版**：整个列表收进一张卡里、行间用细分隔线；序号做成醒目的色块；加减号换成有形状的圆按钮；置顶的那一项不再整行变底色，改成前面一枚小图钉加一行小字说明

### 1.2.0

- **标记为不喜欢**：看到不喜欢的片子，随手点一下就记下来，下次不用再找。三处入口都做了 —— 媒体详情页的「更多」菜单、播放页控制栏、竖屏连播（视界流）的右侧工具栏。按钮按一下标记、再按一下取消，来回切；**长按可以写一句原因**（比如「剧情烂」「画质差」），写完直接生效，不用先标记
- **不喜欢视频管理**：设置里能进，列出所有标记过的条目 —— 缩略图、标题、你写的原因、标记时间。单个条目**往左滑**会露出「取消标记」和「删除影片」两个按钮（蓝 / 红两色区分，滑回去就藏起来），也支持「全部取消」和「全部删除影片」。「取消标记」只是不再不喜欢（可后悔）；「删除影片」会真的把片子从服务器移除并删掉文件，所以单条和批量都要**手动输入「删除」确认**，批量还会显示进度
- **切视频时状态立刻对**：换片、连播下一集时，按钮的亮灭跟着当前这片走，不存在「先亮一下再变暗」。所有页面共用同一份状态，在详情页标的、播放器那边立刻就亮
- **入口可以按需关掉**：设置里分三档开关 —— 详情页菜单项、播放器按钮、视界流按钮，默认都开。关掉播放器按钮时会一并从控制栏布局里移除，重新打开会放回它上次所在的位置；想换位置去「布局」里拖
- **理由会替你留着**：取消标记后记录还在，重新标记时上次写的原因会自动带出来，省得重打一遍

> 「取消标记」和「删除」是两件不同的事：取消只是标记失效，记录和原因都留着（所以管理页里它还在、置灰显示）；删除才是整条抹掉。两者都不可逆的是同一个 —— 删掉之后就找不回来了。

### 1.1.0

- **用词统一为白话**：「猜你喜欢」页里那块原来叫「即混」（Emby 的接口名，普通用户看不懂），现在叫**「连播列表」**；设置里对应的那一项叫「连播列表每行放几个」，说明也改成「一行放几张海报」这类说法

### 1.0.7

- **媒体库浏览**：新增两种浏览样式 —— 「紧凑列表」把标题与副标题叠成一行一条，一屏能看到更多片；「年份」按发行年份自动分组、滚动时带年份小标题。每行个数可在 2～6 之间调（加减键）
- **搜索**：输入时给出联想词（取自片名与搜索历史）；可用类型 chip 限定要搜的类别（全部 / 电影 / 剧集 / 单集 / 合集 / 演员）。同时修掉了此前搜索页出现**两行标签完全一样**的类型 chip、让人分不清以哪个为准的问题（现已合并为一处）。输入联想从横向滑动的小标签改成**输入框下方的建议列表**（最多 5 条）：一屏看全、长片名不再被截断，命中的那几个字还会加粗，一眼就能确认是不是要找的那部。联想列表本身也改成**弹性高度、可收起**——展开时最多三行出头、更多候选在卡片内滚动，点标题行可收起（记住选择），打字结束（键盘收起）或开始滚动结果时还会**自动收起**把空间让给结果，回去改词再自动展开
- **搜索返回**：在首页或媒体库里点开搜索后，用系统返回手势（返回键 / 从屏幕边缘侧滑）现在**只退出搜索状态**、回到原来的列表，而不是直接把整个页面退掉、回到上一层；顶部搜索键此时也一眼能看出是「退出搜索」。退出时**不再重新拉一遍列表** —— 此前会白跑一次请求，随机排序下还会把整个库重新打乱一次；现在列表内容与滚动位置都原样回来
- **播放队列**：列表模式下拖动左侧把手即可给队列排序。拖拽逻辑整套重做 —— 被拖的那一条**完整地跟着手指走**（不再时快时慢、也不会拖到一半突然消失），其余行会平滑让开空位、一眼能看出将插到哪里；队列很长时拖到列表上/下边缘会**自动滚动**接续，一路拖到底不用松手
- **悬浮切换按钮**：左下角常驻的「上一条 / 下一条」小按钮 —— 控制条收起时可用，控制条一展开就自动让位（屏幕中部已经有大的上一集/下一集，不必两个都留）；打开播放队列时也会收起（先前会浮在队列弹窗之上、压住弹窗左下角），关掉队列后恢复；这项在设置里关掉后，任何情况下都不会显示
- **GIF 录制**：修复录制出来是**彩色条纹 / 花屏**的问题。两处根因：一是取帧走的是播放器自带的一套像素转换，开着硬件解码时会把画面转坏（现改走 mpv 自己的截图通道，颜色与屏幕一致）；二是 GIF 编码器的 LZW 压缩里「码宽加宽时机」早了一格，码流从第 256 个码起就损坏、解码器只解得出一小部分。两处都修好后，任何编码格式与硬解组合下都能录出正常画面
- **GIF 清晰度**：录制面板的「清晰度」由三档扩到**五档** —— 320 / 480 / 640 / 960 / 1280，默认仍为 **480**。新增的 960 / 1280 适合看清人脸、字幕与界面文字；档位越高文件越大（同一段 5 秒画面：480 约 1~8MB、640 约 2~10MB、960 约 3.6~9MB、1280 约 6~17MB，大致按宽度平方增长），选择会被记住。输出还会**自动封顶到片源自身的分辨率** —— 源比所选档位窄时不会放大，因为放大只会让文件变大、不会多出细节（先前录出来发糊主要是分辨率偏低，手机上放大后尤其明显）
- **GIF 偏色 / 画面被压平**：修复录制画面**颜色不对**，先后两轮。第一轮是「人像发灰像石膏」：编码用的是一张写死的固定色表，红蓝两色分 6 档、绿色分 7 档，三者的档位对不齐 —— 于是**所有接近灰的颜色都被染成洋红或绿**（中灰走成洋红，暗部又偏绿），中等肤色还会被削掉两三成彩度。改成按每段画面**实际用色**统计的自适应色表后解决。第二轮：自适应色表的首个版本内部有一处下标口径写错，色表会塌缩到十几个颜色，画面被压成几块色斑、**几乎看不出内容**；现已修正，并用真实画面做了逐像素比对验证。现在中性色不偏、肤色正常、连续色阶（天空、暗部、阴影）都保得住。代价是同宽度下文件比旧的固定色表大一些（画面越"干净"的越大），想压体积把清晰度降到 320 就行
- **GIF 体积**：录出来的 GIF 明显变小了。同一段画面里**始终没有变化的部分不再重复存**，只重新编码有动作的那一小块 —— 静止画面、或只有字幕 / 局部在动时大约能省掉九成数据；渐变色与暗部依旧平顺。为免「镜头整体横移」这类几乎全屏都在动的画面反而变大，加了保护：变化范围超过整屏六成时自动改回整帧存储
- **外挂字幕记忆**：修复外挂字幕「加好之后重开 App 就没了」—— 退出时其实已经把它记下来了，问题出在重开时的恢复顺序：选字幕的动作跑在字幕轨真正挂上之前，播放器不认识这条还不存在的轨道，直接把这次选择丢掉了。现在会等所有字幕来源都就位后再统一套用一次上次的选择，重开 App 后上次添加的字幕依然在。顺带把「上次特意关掉字幕」这个选择也记住了 —— 不会再被同名自动加载的字幕重新打开
- **字幕大小与位置**：修复字幕在横竖屏下「对不上」的问题 —— 横屏调好的字号换到竖屏会大出一截，竖屏调好的换回横屏又偏小；位置也会跟着飘（竖屏刚好、横屏偏上）。原因是字幕字号原本跟着**窗口**高度缩放，而竖屏窗口很高、画面只占中间一条，字号就被放大了好几倍。现在字号改为**跟随画面**等比缩放，横竖屏看到的比例一致；位置也改为**贴着画面下沿**，不再落进上下黑边。设置里的「按窗口缩放」相应换成「字幕跟随画面缩放」（默认开启，关掉则回到随窗口大小缩放）
- **快捷收藏**：媒体库卡片右上角的心形可以直接点，点完立即变为实心、同步到服务器（返回列表也不会弹回），并弹一句「已收藏 / 已取消收藏」的提示（失败时提示会替换为失败原因）；**再点一下即可取消收藏**（此前点第二次会又变成「收藏」，怎么都取消不掉，已修）；可在「设置 → Emby 媒体库」里关掉，关掉后心形只作「已收藏」只读角标
- **详情页红心**：修复「只能点亮、取消不了」—— 取消收藏时会回读服务器上的真实状态核对，个别服务端「回了成功但实际上没取消」的情况会被发现，并换用更标准的写法重试；确实取消不掉时会明确提示，而不是假装成功
- **详情页元数据**：修复详情页「更多」里的「刮削元数据 / 刷新元数据」**点了没反应** —— 两个窗口此前只建了开关、忘了挂到界面上，现已接好。刮削 = 按片名 / 年份 / 外部 ID 检索后挑一条应用（与媒体库长按菜单同一个窗口，可选是否连封面一起换）；刷新 = 带「覆盖所有元数据 / 替换所有图片」两个选项的确认框
- **只看未看**：分类行新增「只看未看」快捷开关，一键滤掉看过的
- **演员 / 导演**：长按条目可直接进入「更多 TA 出演的作品」/「更多 TA 执导的作品」（菜单会带上人名，原先是「只看这位演员」，措辞更清楚）；影片没有对应身份时不显示该项
- **同类型推荐**：详情页的「同类型」不再固定用第一个类型 —— 一部片往往同属多个类型，现在每次打开会随机挑一个，看到的推荐每次都不一样；可在设置里关掉、改回固定用第一个
- **推荐开关**：详情页的「推荐」（同演员 / 导演作品）与「同类型推荐」新增一个总开关，默认开启；关掉后详情页不再显示这两块推荐内容（页面更短，也省掉相应的请求）
- **收藏页排序**：排序菜单里当前选项的勾移到右侧，并标出排序方向（如「名称 A → Z」「年份 新 → 旧」）；顶部排序按钮也会显示当前用的排序
- **收藏批量操作**：收藏页长按任意封面进入多选，顶部显示「已选 N / 总数」与全选 / 取消全选；底部是一排批量按钮（标为已看 / 标为未看 / 取消收藏 / 下载，「演员」分类只保留取消收藏）。此前这一排**被底部导航栏整条盖住**、怎么点都调不出来，现已改为进入多选时把底部导航栏收起；返回键也改为**先退出多选**，不再一下把页面退掉。这排按钮本身也重做了外观（图标 + 文字、等宽平分，整块都能点，误触概率更低）；每个动作执行前会**弹窗确认**，做完后底部提示里还能点一下**撤销**（取消收藏 → 收藏回去、标为未看 → 标为已看…）
- **演员作品页**：只显示这个人真实拥有的身份分类（只演戏的人不再出现「导演 / 编剧」两个点了必空的按钮）；顶栏新增随机播放，在当前的筛选范围内打乱连播
- **加载态**：媒体库、收藏、首页、搜索、播放历史、演员作品、分类结果页、详情页统一改成与真实版式同形的**骨架屏**（灰色占位块 + 扫光），不再是一个孤零零的转圈 —— 顺带把「待会儿会出现什么」先摆出来，内容落地时不会整屏跳变
- **离线下载**：排队中的任务可以「置顶」，先下想先看的；新增开关「下载完成后清除服务端播放进度」，打开后本地下完的片子会从其它设备的「继续观看」里消失
- **桌面小组件**：「继续观看」小组件 —— 在桌面直接看到最近没看完的 3 条（封面 + 片名 + 进度），点一下进 App
- **外观**：「设置 → Emby 媒体库」新增分区，可统一调整卡片圆角、封面角标、卡片快捷收藏、详情页推荐开关与同类型推荐随机；详情页顶部按封面主色做渐变
- **演职员合并**：同一个演员因为名字写法不同（中英文 / 括号注释 / 全角半角 / 艺名本名），在服务器上会被当成好几个人 —— 演员作品页少一半片、演职员表出现重复面孔、收藏也对不上。新增工具页「设置 → Emby 媒体库 → 演职员合并」（长按演员卡片也能直接进，会顺手把这位演员带进去）：可以搜演员、扫描全库找疑似重复、一键合并全部同名；同一个人的名字不一样时也能手动并到一起。合并会**写入服务器元数据、所有客户端立即生效**，每一步都先弹确认框把「保留哪条」摆清楚，做完还能在「合并历史」里按批次**撤销**。需要管理员账号，非管理员整页只读；另有一个可选的「合并后自动清理孤立演员」，默认关闭
- **长按复制**：详情页的片名、原名、演职员表里的演员名，以及演员作品页的姓名，长按即可复制（带触觉反馈与「已复制」提示）
- **条目 ID**：媒体详情页与演员作品页显示这条记录的 ID（同样可长按复制），方便在服务端网页端核对是不是同一条
- **演职员合并（同名）**：修复两个名字完全相同的演员条目合并不了的问题（表现是提示已改写若干部作品、回读却仍是原样）。同时修掉演员作品页**只显示前 60 部**（现已按服务端总数全部取回）、以及合并完返回演员页**仍是合并前的旧数据**
- **播放（预解析直链）**：修复开启「预解析直链」后**所有片子都放不出来、甚至闪退**的问题 —— 某些网盘直链会返回拒绝访问，此前没有校验就把这个失败的地址当成有效链接交给播放器。现在遇到拒绝会自动回退到原始地址继续播放

### 1.0.4

- **添加服务器**：服务器地址与端口拆成两个输入框 —— 地址只填 IP 或域名，端口单独填（默认 8096）；勾选「使用 HTTPS」时端口自动切成 443，取消勾选切回 8096（已经手填过自定义端口的不会被改掉）。整段粘 `http://192.168.1.10:8096` 也能自动拆好
- **老旧编码兼容**：AVI / Xvid（MPEG-4 ASP，fourCC 常见 XVID / DIVX / MP42）这类片子 —— 播放器不再把画面交给手机的硬件解码器。这类容器不携带硬件解码器需要的参数，硬解会「解码器建起来了、一帧也吐不出来」，表现就是**有声音、画面全黑**；现在这类编码一律由 mpv 的软件解码接手。GSY 备用内核遇到本机解不了的容器（AVI / WMV / RMVB…）也会**自动换到自带 ffmpeg 的 IJK 内核并重试一次**，不用再自己去设置里翻内核
- **服务器转码播放**：详情页「更多」菜单新增该入口。直连播不动的片子（手机解不了的老编码、strm 指向的远程 AVI）改由服务器转成 H.264 + AAC 再下发；转码会占用服务器 CPU，所以做成手动入口、不自动触发
- **远程流**：加强网络流的预读缓冲与断线重连（抖一下能自己接上，不再一路卡到重进页面），网络读取缓冲区由 128 KiB 提到 4 MiB
- **媒体库置顶**：长按首页的媒体库卡片可以「置顶」，最多 2 个、最后置顶的排最前；置顶的卡片右上角钉一枚小图钉，一眼看得出钉住了哪几个。菜单里「置顶 / 取消置顶」是同一个入口，状态变了文案跟着变
- **媒体库顺序**：新增「调整顺序号」——一屏里给每个媒体库调先后，序号越小越靠前。改成别人已占用的序号时两者自动互换；新出现的媒体库自动排到最后，不打乱已排好的顺序。置顶的库永远排在最前，所以序号为 1 的库也排在它们之后
- **投屏进度条**：可以拖了（原来只能点一下定位），拖动过程中实时显示「定位到 时:分:秒」，松手按整秒落点；另加 ±1 秒 / ±10 秒 微调键，长片也能定位到秒
- **外部播放器**：详情页的「外部播放器」按钮升级为**应用内选择列表**，自动列出手机里所有能播放视频的播放器 —— MX Player、VLC、nPlayer、Just Player、Kodi 这类常用播放器排在最前，其余按名称排在后面，每项带应用图标，上次用过的那个打勾。列表里不会出现影屿自己（点了等于原地打转），底部保留「系统选择器」当兜底。此前只查一次带流地址的 intent，只注册了本地文件类型的播放器会因为 scheme 对不上而整个消失、列表里只剩「视频」，现已修正
- **视界流加载**：修掉刚进播放器时「加载圈消失、画面闪一下」—— 之前加载圈撤得太早，撤掉的那一刻画面其实还没显示出来，中间露出的一小段黑屏就是那下闪烁；现在等画面真正画到屏幕上才撤圈，并让加载圈淡出而不是硬切
- **视界流进度条**：修掉每切一条视频、下方进度条就消失重绘一次的跳动 —— 时长未知时不再换成另一套控件，整条进度条形态保持稳定
- **视界流**：媒体库工具行新增入口，竖屏上下滑连播；随机条数可在设置里改（默认 100）。翻页走播放器原生滚动（甩一下能连着翻的手感），左右边缘调亮度 / 音量、横拖调进度；截图存相册、出错可重试
- **视界流手势**：翻页由「自己逐帧喂位移」改回 Pager 原生滚动 —— 原先没有速度惯性，两条视频像粘在一起被手指拖着走，滑完还容易弹回原处。左右两条边缘带收窄到 48dp（原来右侧占屏宽 25%，右手拇指的自然落点就在里面，想翻页经常被当成调音量）；音量指示条改到右侧显示，不再和亮度一样都挤在左边
- **视界流误触**：修掉滑动被误判成点击的问题 —— 单击 / 双击的判定层不再压在整个播放器之上，滑动开始后也会被消费，划一下不会再把「收藏」点掉
- **视界流画面**：修掉「划了几条之后某条只有声音、进度条在走、画面全黑」—— 相邻页在滑动中会多预组合一页，超出保留窗口的那页实例被回收后，画面 View 还在屏幕上却再也接不回去；现在翻页会把窗口内三页的接线重新接一遍，并有心跳兜底自愈
- **视界流横竖屏**：修掉「点翻转，播的却是下一条」—— 屏幕尺寸一变，翻页器会按新的页高重新换算滚动偏移，顺势吸附到相邻页上；现在切换方向时会把页锚回原来那一条，并在一小段窗口内不采信页码变化。画面尺寸也改为每次按屏幕实测尺寸重算，不再出现「翻转后比例崩掉」
- **视界流显示比例**：一律完整显示、不裁画面（原来只在横屏视频时留边，竖屏视频仍会裁掉上下）
- **搜索**：媒体库与首页顶栏的搜索按钮跟着状态换图标（放大镜 ↔ 放大镜加斜杠），进搜索后一眼知道从哪儿退出
- **媒体库**：新增「演员」分类，演员卡片左下角带作品数角标（角标数字与点进该演员后看到的条数一致）；修复媒体库内搜索搜不到演员的问题（演员走 `/Persons` 端点，且不再被列表那层「只留可播放条目」的本地兜底剔掉）

- **扫描媒体库**：长按首页的媒体库卡片、或库内的文件夹，可让服务器重新扫描该目录（走官方 `Items/{id}/Refresh`，异步执行），新入库的文件下拉刷新后即可看到
- **下拉刷新**：首页与详情页支持下拉刷新
- **媒体库**：按库记住上次选择的分类，从文件夹返回后不再跳回「全部」
- **详情页**：顶部恢复为整张剧照铺满；右上角的收藏与已看标记加了结果提示，失败会回滚并说明原因
- **稳定性**：过滤掉 strm 指向远程文件时服务端误报的异常条目（名称形如 `http:`），点击不再崩溃

## 构建

前置：JDK 17、Android SDK（build tools 34.0.0+）、Git。

```bash
./gradlew.bat --no-daemon -Pabi=arm64-v8a --console=plain :app:assembleStandardDebug
```

产物在 `app/build/outputs/apk/standard/debug/`。可选 ABI：`arm64-v8a`（推荐）、`armeabi-v7a`、`x86`、`x86_64`、`universal`。

> 依赖来自 Google Maven、Maven Central 与 JitPack。若本地 Gradle 挂了「只走单一镜像」的 init 脚本，会导致仅托管在 Maven Central 的依赖（如 `io.github.marlboro-advance:mpv-android`）解析失败。
>
> Emby 官方 Java SDK（`embyclient`）与 UPnPCast（DLNA 投屏）均以源码形式内置，不走 Maven。
