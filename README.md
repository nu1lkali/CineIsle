**一个打通 Emby 的本地播放器 —— 基于 mpvEx 二次开发**

包名 `app.cineisle.player` · 当前版本 `v1.0.3` · 构建变体 `standard` · 双播放内核（mpv / GSYVideoPlayer）

## 项目背景

一开始用的是某款第三方 Emby 播放器。用着还行，但总有些自己想要的功能它没有，于是去提需求——作者不太愿意做，也没怎么回复。

那没辙了，自己做呗。

从零写一个播放器内核不现实，所以找了一个足够扎实的播放器做底座：**[mpvEx](https://github.com/marlboro-advance/mpvEx)**（底层是 mpv-android / libmpv）。mpvEx 本身是一个好用的**本地**播放器，但不带 Emby 客户端。

于是就有了 **影屿 / CineIsle**：在 mpvEx 上补出一整套 Emby 客户端，再把那些「自己用得上」的功能一个个加上去。

名字取自「电影的岛屿」——把自己想看的片子收在一个地方。

## 功能

### Emby 客户端（本项目从零实现）

mpvEx 原本只做本地文件与网络流播放，没有任何「媒体服务器」概念。本项目在它之上补出了一整套 Emby 客户端，**不只是把一个 URL 丢给 mpv**。

#### 服务器与账号

- 多服务器管理：添加 / 编辑 / 删除 / 切换；地址支持 `http://主机:端口` 与 `https://域名` 两种写法（自动解析协议、主机、端口）
- 用户名 + 密码登录，走 `POST /emby/Users/AuthenticateByName` 拿 `AccessToken`；**登录成功才入库**，避免存下无效配置
- 服务器配置用 Room 持久化（新增 `emby_servers` 表与 DAO），当前选中服务器另记一处，重启后自动恢复；**密码落盘前加密**（见「安全与隐私」）
- 登录态自检与自动重登：`ensureLoggedIn` / `relogin`，Token 失效时不至于整个界面变砖
- 首页顶栏可下拉直接**切换服务器**，或一键进「Emby 服务器」页添加 / 编辑 / 删除
- `GET /System/Info/Public` 探测服务器信息

#### 导航结构

底部五个 Tab，前三个都是 Emby：**首页 / 收藏 / 历史**；后两个保留上游的**文件夹 / 网络流**。

- 收藏：`IsFavorite` 过滤的收藏列表
- 历史：`GET /Users/{UserId}/Items` 取播放历史，行式布局带进度
- 首页顶栏集中了**全局搜索 / 切换服务器 / 下载管理 / Emby 维护 / 设置**入口，下载管理图标带进行中任务数角标

#### 首页

- **媒体库入口**：横排大卡片，显示库名、条目数、库封面；按 `CollectionType`（电影 / 剧集 / 音乐…）配图标
- **继续观看**：宽幅卡片 + 底部播放进度条，左下角还有「剩余 XX分XX秒」炭黑角标
- **最新加入**：海报卡片，`Primary` 取不到图时自动回退 `Thumb`
- **全局搜索**：顶栏搜索键展开输入框，跨**全部媒体库**搜索（输入 400ms 防抖），结果直接替换首页内容
- **搜索类型筛选**：搜索框下方一排 chip —— 全部 / 电影 / 剧集 / 单集 / 合集 / 演员。默认「全部」＝不加类型限制；勾了具体类型就只查那一类（可多选，「全部」自动让位），所以合集和演员第一次变得搜得到
- **搜索历史**：搜索框为空时显示历史词条，点一下直接搜；可单条删、可一键清空。历史存 Room，与媒体库内搜索**共用同一份**（上限 20 条，按最久未用淘汰）
- 加载中 / 空状态 / 错误重试三种状态齐全

#### 媒体库浏览

- **分类**：全部 / 继续播放 / 合集 / 收藏 / 文件夹
- **排序**：名称 / 加入时间 / 播放时间 / 发行年份 / 首播日期 / 评分 / 影评评分 / 时长 / 播放次数 / 随机（参数值与 Emby `/Items` 的 `SortBy` 对齐）；切换排序方式或升/降序后列表**回到第一条**，不会停在上一次浏览的位置
- **卡片样式**：海报 / 背景图 / 横幅，比例与取图类型（`Primary` / `Thumb`）联动
- **文件夹下钻**：容器类条目（`Folder` / `CollectionFolder` / `UserView` / `BoxSet`）自身没有 `Primary` 图，用内部子媒体的缩略图拼 2×2 宫格封面
- **两种随机**：本库随机播放、**只在本库收藏里**随机播放
- **搜索**：库内搜索框，输入后 400ms 防抖再发起查询；同样带**类型筛选**与**搜索历史**，历史与首页共用一份
- **状态保持**：排序方式与卡片样式持久化，重进 App 仍沿用；列表结果 + 滚动位置做进程内缓存，从详情页或播放器返回时不重新发请求、并停回原来那一屏（**主动改排序 / 改升降序时例外**，那时会归位到第一条）
- 下拉刷新

#### 媒体库筛选

工具行的漏斗图标打开筛选面板（从底部上划）。**每一项点下去立刻生效**，不用再点「确定」——结果就在下面的列表里，边看边调更省事；面板标题行有「恢复默认」，一键清空全部条件。有生效条件时漏斗图标会高亮，一眼能看出列表不是全量。

可筛的维度：

- **类型 / 标签 / 年份 / 官方分级**（多选，取值来自该库里真实出现过的项）
- **演员 / 导演**、**工作室**（多选；按 ID 筛，同名不同人也能区分）
- **播放状态**（已看 / 未看）、**清晰度**（高清 / 标清）、**3D**、**字幕**（有 / 无）
- **评分**（最低分门槛）
- **只看收藏**
- **中文字幕**（见下节）

每个媒体库的筛选条件**各自记一份**，退出再进、甚至重启 App 都还在。

#### 中文字幕筛选（按路径标记）

Emby 服务端没有「中文字幕」这个筛选维度，所以这是**客户端**能力：对条目的**路径**做匹配，命中才算。

- 主标记是 `-C`；默认还支持 `-CHS` `-CHT` `CHI` `CHINESE` `GB` `BIG5` `中文字幕` `中字` `中文` `简体` `繁体` 等一批常见写法
- **标记表可配置**：筛选面板里「编辑标记」可以增删（保存后自动重扫），也可以一键恢复默认；匹配范围可选「整条路径（含目录名）」或「仅文件名」
- 标记带边界限定：`-C` 不会误命中 `-CD` / `-CH` / `-CM`，`CHS` 也不会命中 `CHSDVD` 这类粘连串
- 多版本条目会把每条媒体源的路径都看一遍，不只取一个字段
- 打开开关后对整库做一次完整扫描（服务端筛不了，只能拉全再筛），工具行显示「扫描中… 已扫 N/M · 命中 K」，**边扫边出结果**，不用等扫完
- 命中的卡片副标题会标出是哪个标记命中的（例如 `2024 · -C`）

#### 详情页

- 顶部 Backdrop 剧照 + 标题 / 副标题 / 评分 / 时长等 meta 摘要
- **播放区**：根据 `UserData.PlaybackPositionTicks` 显示上次进度，按钮文案变成「继续播放 · mm:ss」；真看过的片子额外给「从头播放 / 继续上次」两个按钮；旁边有**投屏**入口
- **剧集**：季 / 集两层结构，逐季展开选集
- **演职员**：头像点一下进**演员作品页**（按 `PersonIds` 查 TA 参与过的片子）
- **类型 / 标签 chip**：点一下进**作品页**（跨全部媒体库按 `Genres` / `Tags` 查）
- **媒体信息**：容器、视频编码、分辨率、帧率、码率、音频编码与声道、字幕轨、文件大小、加入时间、首播日期（解析 `MediaStreams`，语言标签本地化）
- **更多菜单**：编辑元数据（名称 / 原名 / 简介 / 年份 / 类型 / 标签 / 制作地区 / 工作室 / 评分 / 分级 / 演职员增删）、刮削元数据、刷新元数据、删除媒体（带二次确认）
- **媒体操作**：收藏 / 取消收藏、标记已播放 / 未播放
- **离线下载**：播放区里一键把该媒体加入下载队列；按钮会跟着任务状态变成「下载中 37% / 已暂停 / 已下载」，不会重复入队

#### 播放与进度同步

- **直链播放**：`GET /emby/Videos/{Id}/stream?static=true`，不转码、交给本地内核解码，URL 内自带 `api_key`（界面上显示时会打码，见「安全与隐私」）
- **剧集连播**：把同一季 / 同一剧集的集号拼成播放队列，随 intent 传入 `playlist` 与 `playlist_titles`，因此切集时标题正确，随机与循环也能正常工作
- **进度回传**：`/Sessions/Playing`（开始）、`/Sessions/Playing/Progress`（每 10 秒一次）、`/Sessions/Playing/Stopped`（暂停 / 退出 / 切集），手机、电视、网页之间进度互相同步
- **播放页内的 Emby 操作**：播放器工具栏的 Emby 收藏按钮（弹跳 + 星光 + 红心渐变动效）；切集时自动刷新当前条目的收藏 / 已看状态
- **外挂字幕**：`GET /Videos/{Id}/{MediaSourceId}/Subtitles/{Index}/Stream.srt` 拉下来交给播放内核
- **图片按需取尺寸**：`Primary` / `Backdrop` / `Thumb` 按卡片宽度请求合适尺寸，少下流量；封面等图片另有磁盘缓存（见「设置」）

#### 离线下载（带暂停 / 断点续传）

- **下载接口**：`GET /emby/Items/{Id}/Download`，拿服务器上的原文件（不转码），支持 `Range` 请求
- **落盘位置**：Android 10+ 直接写**公共 Download/CineIsle 目录**——先用 `MediaStore` 以 `IS_PENDING=1` 占位，下载完成再置 0 发布，因此下载中的半成品不会出现在文件管理器里，也**不需要任何存储权限**；Android 9 及以下回落到应用外部私有目录
- **暂停 / 继续**：暂停时把已下字节原样留在目标文件里、只取消网络请求；继续时新请求带 `Range: bytes=<已下>-`，以追加模式接着写，真正做到断点续传，不会重头再下
- **中断保护**：服务器断流（Wi-Fi 掉了、进程被杀）时任务落到「已暂停 · 可继续下载」，重开 App 也能接着下
- **并发与队列**：同时最多下 2 个，其余排队；支持「全部暂停 / 全部继续」
- **下载管理页**：进度条（总量未知时走不确定进度动画）+ 百分比 + 已下/总量 + 实时速度 + 预计剩余时间；每条任务可单独暂停、继续、取消、重试、移除记录；完成后可「打开」
- **任务持久化**：任务元数据存 SharedPreferences，重启后未完成的任务保持在「已暂停」等待续传
- **为什么不用系统 DownloadManager**：它没有公开的暂停/继续 API，满足不了「暂停下载 / 继续下载」的需求，所以这里自己基于 OkHttp 实现

### 双播放内核（mpv / GSYVideoPlayer）

默认内核是功能最全的 **mpv**；另备一个 **GSYVideoPlayer** 内核，底层还能再挂 IJK / System / ExoPlayer 三种解码通道。做双内核的原因是兼容性：有些片子在某些设备 / 某些编码上换个内核就顺了。

**怎么切：**

- 在「设置 → 播放与控件 → GSY 播放器」里选**默认内核**
- 播放页内也能切：mpv 页「更多 → 用 GSY 播放」，GSY 页顶栏一键「切回 mpv」；切换时会带上播放队列、标题、当前进度和 Emby 上下文，不会从头开始
- 筛选面板 / 详情页**长按**播放按钮，可以用另一个内核直接起播

**GSY 播放页**的控件照着 mpv 播放页重新画了一套（不是直接套 GSY 的默认外观）：顶栏返回键 + 标题 + 切换内核，底栏进度条与两行按钮条，正中播放键与上/下一集，右下角一个方向键负责竖屏↔横屏。

GSY 页提供的能力：**倍速 / 循环 / 锁屏 / 画面滤镜（GL）/ 显示比例 / 渲染载体 / 静音 / 截图 / 字幕（外挂、可调延迟）/ 音轨选择（仅 IJK 内核）/ 画中画 / 投屏 / 收藏**，以及上下一集与内核切换。

mpv 独有的能力（滤镜链 / 去色带 / GLSL 着色器 / 字幕排版 / 第二字幕 / 解码器面板 / 章节 / 统计信息）在 GSY 页没有对应入口——这类入口是**直接不显示**而不是置灰，避免点上去没反应。

GSY 有**独立的一整页设置**（和 mpv 完全隔离，改哪边都不影响另一边）：默认内核、长按用另一内核、GSY 解码内核、硬解与失败回退、渲染方式、显示比例、画面滤镜、循环、起播倍速、变速不变调、边播边缓存、续播、播完自动退出、进入即静音、手势开关与灵敏度、控件自动隐藏、屏幕锁、全屏方向与安全区、按 Home 自动进小窗等。

### DLNA 投屏

- **实验性功能**：自动发现局域网里的 DLNA 接收设备，选中即可投；面板里能遥控播放 / 暂停 / 停止，并拖音量
- 入口有两个：媒体**详情页**的投屏按钮，以及**播放页内**的投屏按钮
- mpv 与 GSY 两套播放页共用同一套投屏，行为一致

### 播放体验

- **视频预加载**：当前视频播放 2 秒后，后台对下一个视频的流地址发一个带 `Range` 头的请求，预取开头约 2MB。切集时首帧来得更快，观感更接近「无缝」。可在「设置 → 播放器」里开关，默认关闭（预加载会额外占一点带宽，弱网 / 流量环境请自行决定）。
- **连播下一集倒计时**：片尾弹出「下一集」卡片，倒数 N 秒后自动切集；点卡片立刻播，点右边的叉则本集播完停住。倒计时秒数可调，设为 0 就是「播完直接切」的老行为。
- **记住每部剧的播放速度**：同一部剧切下一集时沿用上一集调过的倍速（电影按单部记），默认关。
- **记住每部剧的音轨**：按「语言 + 编码 + 声道」匹配，下一集自动选中同一条音轨，默认关。
- **切集不再重置屏幕方向**：以前横屏看片时切下一集，会被偏好设置（比如竖屏）强行拉回去。现在旋转按钮指定的方向会在本次播放会话内保留，随机播放也一样。
- **「从头播放」真的从头了**：以前点详情页的「从头播放」，还是从上次停下的位置接着播——因为播放器启动后会用本地续播记录覆盖掉 `time-pos`。现在「从头播放」会带一个一次性标记，播放器读到时跳过本地续播恢复；标记只对本次启动的第一个视频生效，剧集连播时后续剧集照旧恢复各自进度。
- **随机播放标题修复**：随机播放进入时，除第一个之外的视频标题都显示成 `stream`。根因是 Emby 的流地址末段固定为 `/stream`，播放器只能从 URL 猜片名。改为由发起播放的一方把真实标题列表随 intent 传进来，切集时优先使用。

### 界面

- **竖屏底部控件精简**：把随机播放、画面缩放、显示比例等不常用的按钮收进「更多」，竖屏下不再一堆按钮抢视觉；上/下一集固定在正中播放键两侧，不占按钮条。
- **控件按钮可自定义**：设置里能编辑播放页按钮条显示哪些按钮、排什么顺序。
- **设置可搜索**：设置首页顶部有搜索框，敲关键词直接定位到具体设置项。
- **图片缓存管理**：「设置 → 数据与缓存」里可查看 Emby 封面等图片的缓存占用并一键清除（缓存 7 天有效）。
- **首页媒体库标题垫底色**：库名一开始靠整片渐变遮罩压暗来保证可读性，结果遮罩几乎盖住半张卡片。改成和「继续观看」剩余时长角标同一套做法——只给库名垫一块圆角实心底色，封面主体完整露出来，文字也一定落在实色上。
- **角标底色换成中性炭黑**：这类垫底角标原先用深蓝（`0xFF0B2E5B`），在暖色封面和偏紫的主题下太跳。换成取自暗色背景那一族的中性炭黑（`0xFF262229`，85% 不透明），库名与剩余时长两处共用，配白字在任何封面上都稳。
- **继续观看剩余时长角标**：首页「继续观看」每张缩略图左下角显示「剩余 XX分XX秒」，炭黑底。
- **继续观看去掉居中播放按钮**：单击是进详情页而不是直接播放，中央那个三角图标会让人误以为「点了就播」，因此移除。
- **启动页**：冷启动显示 logo + 应用名（影屿 / CineIsle）。
- **关于页**：移除捐赠与更新入口，标题改为项目名，保留对 mpvEx 的致谢。

### 设置

设置分成几组：**界面与外观**（外观、控件布局）、**播放与控件**（播放器、手势、GSY 播放器）、**文件管理**（文件夹）、**媒体设置**（解码器、字幕、音频）、**数据与缓存**（图片缓存）、**高级与关于**。GSY 播放器设置单开一页，与 mpv 的偏好严格隔离。

### 安全与隐私

**服务器与网络连接的密码加密落盘。** Emby 密码，以及 SMB / FTP / WebDAV 的密码，进数据库前统一用 Android Keystore 里的 **AES-256-GCM** 加密：

- 密钥由系统 Keystore 生成并保管，**不可导出**、不落盘、不进备份——光拿到 `mpvex.db` 也解不开（root、adb backup、云备份同理）
- 密文格式 `enc:v1:<iv>:<密文>`；不认这个前缀的一律按旧版明文原样读，所以**老数据不需要迁移脚本**，App 启动时后台把明文就地重加密一次（幂等，重复跑无副作用）
- GCM 的 IV 每次随机生成，同一个密码两次加密结果不同，密文之间无法比对
- 约定「**数据库存密文、内存存明文**」，加解密只收口在仓库层，网络客户端与界面代码一行都不用改
- 加密失败时宁可**拒绝写入**（按未设密码处理，让用户重输），也不会悄悄退回明文
- 代价：卸载重装 / 清除应用数据后 Keystore 密钥一并消失，旧密文解不开，需要重新输一次密码——此时数据库本来也被清空了，算可接受

**备份文件不带密码。** 「导出设置」出来的 XML 是明文的，所以导出时**主动丢弃所有连接与服务器的密码**，导出完成弹窗会列出哪些连接需要重输；导入后把这些密码补上即可。

**播放器不再显示直链里的 api_key。** Emby 的播放直链形如 `.../stream?static=true&api_key=xxx`，mpv 在取不到片名时会把**整条 URL** 当作 `media-title` 回传，顶栏标题、通知栏、投屏名于是把 token 一起亮出来。现在这些**纯展示**的位置统一过一遍脱敏（`api_key` / `token` / `access_token` / `password` / `sig` 等 query 参数的值打码成 `***`）；**交给播放内核的地址始终是原始的那一份，播放不受任何影响**。

### 中文本地化

补齐了大量此前仍是英文的界面文案：

- 滤镜预设名与说明（12 个预设）
- 播放配置名（高质量 / GPU 高画质 / 低延迟 / 软件快速等）
- 进度条样式名（标准 / 波浪 / 粗条）
- 播放器控件名（返回 / 视频标题 / 章节 / 播放速度 / 解码器 …）
- 网络页（stream link / local network 等）
- 排序与视图弹窗（标题 / 日期 / 大小 / 时长 / 视频数，A-Z / Z-A / 最早 / 最新 / 最小 / 最大 / 最短 / 最长，显示项、N 列、展开 / 收起、视图模式与布局、文件夹与视频宫格）
- 播放器设置、手势设置、高级设置，以及各类说明文本

下拉枚举以前会直接露出英文常量名，现在统一走 `valueToText` 显示本地化文案。

排序选项这里有个坑：枚举名（`Title` / `Date` / `Size` / `Count` …）**同时是写进偏好的持久化键**，直接改成中文会让老用户的排序偏好全部失效。所以显示层另走一层映射——枚举上加一个 `label`（中文）给界面，`displayName`（英文）继续当键，弹窗通过 `typeLabel` 把键翻成文案。

### 继承自 mpvEx

本地文件播放、Material 3 Expressive 界面、SMB / FTP / WebDAV、外部音轨与字幕、手势控制、画中画、后台播放、Anime4K 着色器等上游能力全部保留。

## 构建

### 前置条件

- JDK 17
- Android SDK（build tools 34.0.0+）
- Git

### 打包 arm64-v8a

```bash
./gradlew.bat --no-daemon -Pabi=arm64-v8a --console=plain :app:assembleStandardDebug
```

产物位于 `app/build/outputs/apk/standard/debug/`。

可选 ABI：`arm64-v8a`（现代 64 位 ARM 设备，推荐）、`armeabi-v7a`、`x86`、`x86_64`、`universal`。

> 依赖同时来自 Google Maven、Maven Central 与 JitPack。若本地 Gradle 全局配置里挂了「只走单一镜像」的 init 脚本，会导致仅在 Maven Central 上的依赖（如 `io.github.marlboro-advance:mpv-android`）解析失败，请先移除。

> Emby 官方 Java SDK（`embyclient`）与 UPnPCast（DLNA 投屏）均**以源码形式内置**在 `app/src/main/java/` 下，不走 Maven，构建时不需要额外拉取。
