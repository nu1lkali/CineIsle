本次改版（关于页设备信息面板 + 图标）
  • 设备面板不再是「浅蓝实心卡」：改成浮在主卡渐变之上、共用同一呼吸相位的玻璃层——极淡磨砂 + 随 5s 相位游走的柔光 + 顶部高光 + 上亮下暗的玻璃内描边，底下那片彩色渐变照旧透出来，因此有渐变、会呼吸、有质感，也不闷。
  • 层次靠「分组主色引导条 + 图标 + 三级排版」建立，而不是靠一整块底色或一堆分隔线，既避开浅蓝也避开单调。
  • 按钮 / 状态行 / 面板标题 / 分组标题 / 复制胶囊全部配对应图标。GitHub 按钮用官方猫头标（单色 vector drawable，随 tint 适配主题），其余取自 material-icons-extended，逐个核对 AAR 存在性。
  • 落代码：AboutGlassButton / AboutActionRow 新增 icon 参数；DeviceInfoPanel 新增 breath 参数，由主卡的 fraction 传入，drawWithCache 内自绘玻璃与呼吸光斑。
  • 内容色仍一律取自 MaterialTheme.colorScheme.onPrimaryContainer，玻璃高光用白色透明度，深浅主题自动适配，无硬编码 UI 色。
